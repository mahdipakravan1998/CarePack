## قواعد پذیرش

- Headingها باید با Semantics مشخص باشند و ترتیب خواندن از عنوان به محتوا و سپس Actionها برسد.
- هیچ Action فقط با رنگ یا آیکن بی‌نام قابل تشخیص نباشد.
- تمام Actionهای مخرب باید نام روشن، Focus قابل پیش‌بینی و Confirmation قابل خواندن داشته باشند.
- در ۲۰۰٪ Font هیچ Action اصلی خارج از دسترس یا روی متن دیگر قرار نگیرد؛ Scroll مجاز است.
- در RTL، ترتیب منطقی دکمه‌ها، اعداد فارسی و تاریخ جلالی باید حفظ شود.
- Live region فقط برای تغییر وضعیت لازم استفاده شود و تکرار آزاردهنده ایجاد نکند.
- Contrast متن و کنترل‌ها باید با ابزار معتبر بررسی و Evidence آن نگهداری شود.
- هیچ ردیفی تا زمان پیوست Evidence واقعی بسته تلقی نمی‌شود.
